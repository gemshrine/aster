# 0008 — UI: дизайн-система и раскладка клиента

- **Status:** Accepted
- **Issue:** #10

## Проблема

`crates/client` — пустой скаффолд (`main.rs` рендерит заголовок). Issues #5 (shell), #6 (чат + история), #7 (звонок) будут рисовать UI, но нет ни токенов, ни раскладки, ни описания состояний компонентов — каждый issue начнёт изобретать своё, и экраны разъедутся.

Параллельно существует дизайн-канвас **«Aster — Desktop Chat Client»** (Claude Design, 4 артборда: `Main`, `DirectMessage`, `VoiceCall`, `Spec`), где уже зафиксированы цвета, типографика, сетка и состояния компонентов. Нужно решить, что из него берём, а что нет.

### Расхождение канваса с `0001`

Канвас нарисован как Discord-подобный клиент: server rail (5 серверов), список каналов, member list на 11 человек, DM-список, групповой звонок на 5 плиток. `0001` явно объявляет групповые чаты/звонки и роли **вне скоупа**: сервис на двух человек.

Берём из канваса **визуальный язык** (токены, типографика, компоненты, поведение) и раскладку экрана DM/звонка, **не берём** сущности «сервер / канал / участники / список DM».

## Предлагаемое решение

### Визуальный язык (переносится как есть)

Артборд `Spec` — источник правды. Копируется в `crates/client/styles/tokens.css`:

- **Поверхности:** `--bg #131117`, `--bg-elevated #18151d`, `--bg-panel #1c1922`, `--bg-panel-2 #26212e`, `--bg-input #2a2532`, `--border rgba(255,255,255,.07)`.
- **Текст:** `--text-primary #f3f0f7`, `--text-secondary #a79fb5`, `--text-tertiary #6f6880`, тело сообщения `#dcd7e6`.
- **Акцент/статусы:** `--accent #a392dd` (+ `--accent-soft` 16%, `--accent-dim` 55% на чёрном), `--rose #d3a6ac`, `--sage #9fbba4` (online), `--idle #d8bd6f`, `--danger #c97b72` (leave call).
- **Шрифты:** Instrument Serif Italic (display/инициалы аватара), Hanken Grotesk (UI/текст). Обе — Google Fonts, **вшиваются в бандл** (`crates/client/assets/fonts/`), не тянутся из сети: клиент десктопный и должен запускаться офлайн.
- **Радиусы:** 4 / 8 / 9 / 12 / 16 / pill, `--r-arch 28px 28px 14px 14px` (плитка звонка).
- **Моушен:** `--ease cubic-bezier(.2,.8,.2,1)`, `--dur-fast 120ms`, `--dur 150ms`.
- Только тёмная тема в v1.

### Раскладка (адаптация под двух пользователей)

Окно 1440×900, минимум 1024×640. Три состояния главного окна вместо четырёх экранов канваса:

```
┌──────────────────────────────────────────────┐
│ title bar 44                                 │
├──────────┬───────────────────────────────────┤
│ sidebar  │  чат / звонок (flex 1, min 480)   │
│   264    │                                   │
│          │                                   │
├──────────┴───────────────────────────────────┤
```

- **Title bar (h 44):** системный — `decorations: true` в `tauri.conf.json`, кнопки окна рисует WM. Внутри окна вместо него верхняя полоса h 44 с именем собеседника и статусом подключения к signaling-server (`0003`: connected / reconnecting / offline); кастомный title bar из канваса не воспроизводим.
- **Sidebar (w 264):** вместо server rail + списка каналов — карточка собеседника (аватар 38, имя, presence из `PeerStatus`), кнопка «Позвонить», ниже — панель себя (`0006`: кто я, mute-тоггл). Server rail (76px) **не делаем**.
- **Основная область:** лента сообщений (px 22, gap 15, avatar 38, max-width текста 720) + композер (mx 22, mb 20, h 52, r 16). Member list и profile panel из канваса **не делаем** — собеседник один, его карточка уже в sidebar.
- **Звонок:** активный звонок занимает основную область поверх ленты (как `VoiceCall`, но 2 плитки вместо 5, r-arch, ring при speaking) + полоса контролов: mic, headphones, screen (позже), leave. При свёрнутом звонке — компактная строка «Voice connected» в sidebar, как на канвасе.

### Компоненты (первый набор, Leptos)

Каждый — отдельный модуль в `crates/client/src/ui/`, состояния по артборду `Spec`:

| Компонент | Состояния | Метрики |
|---|---|---|
| `IconButton` | default / hover / toggled / danger / sm | 32 r8 icon 18; sm 26 icon 15 |
| `Avatar` | online / idle / dnd / offline / speaking | 18–88, кольцо 12, обводка 2.5 цветом фона |
| `TextField` | default / focus / error / disabled | h34 r9 px12 |
| `Message` | обычное / продолжение группы / вложение / статус отправки | группировка одного автора < 5 мин без аватара |
| `Bubble` | in / out / подряд (углы 6) | max 520, p 10/14, r18 |
| `Composer` | default / disabled (нет связи) | h52 r16, send 34 |
| `CallTile` | default / speaking / muted | r-arch, ring 3px accent 30% |
| `CallControls` | default / hover / off-muted / leave | 46 pill, leave h46 px20 |

Статусы сообщения из `0004` (`Sending / Sent / Delivered / Queued`) рисуются под последним пузырём группы 11px `--text-tertiary`; канвас их не покрывает — это добавка к нему.

### Иконки

Lucide (MIT), 24×24, stroke 1.6, round caps, `currentColor` — как рекомендует канвас. Нужный набор инлайнится в бандл, пакет целиком не тянем.

### Порядок работ

1. `ui: tokens.css + шрифты + иконки` — базовый слой, без логики.
2. `ui: примитивы` (IconButton, Avatar, TextField) + страница-витрина состояний (dev-роут, не в релизном билде).
3. `ui: shell` (title bar, sidebar, presence) — вливается в #5.
4. `ui: чат` (Message, Bubble, Composer, статусы) — вливается в #6.
5. `ui: звонок` (CallTile, CallControls) — вливается в #7.

## Альтернативы

- **Взять канвас целиком, включая серверы/каналы** — отклонено: противоречит `0001` (не-цель «групповые чаты»), это месяцы работы на функциональность для двух человек.
- **Tailwind / готовая CSS-библиотека** — отклонено: канвас уже даёт полный набор токенов, а лишний тулчейн (Node) прямо против стека из `CLAUDE.md`.
- **Светлая тема в v1** — отклонено: контраст канваса проверен только для тёмной; тема добавляется позже сменой значений токенов.

## Затронутые компоненты

- `crates/client` (Leptos: `src/ui/`, `styles/`, `assets/fonts/`)
- `crates/client/index.html` (подключение токенов и шрифтов)

## Решения по открытым вопросам

- **Акцент** — как в канвасе: `--accent` остаётся темизируемым токеном, дефолт `#a392dd`; все 4 варианта акцента проверены на контраст (белый на `--accent-dim` ≥ 4.5:1), смена — одним значением токена. Пользовательская настройка выбора — позже, v1 не блокирует.
- **Title bar** — системный (`decorations: true`). Дешевле, не ломает тайлинг-WM на Linux; внутренняя полоса h 44 несёт только контент, не управление окном.
- **Витрина компонентов** — только dev-сборка (`#[cfg(debug_assertions)]` + dev-роут), в релизный бандл не попадает.
